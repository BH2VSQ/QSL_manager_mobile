# Android 品牌配置

本版本已经把 Android 工程直接纳入源码，因此 clone 或解压后即可使用。

| 项目 | 值 |
|---|---|
| 应用显示名称 | `QSLMM` |
| Application ID | `cn.bh2vsq.qslmanager` |
| Namespace | `cn.bh2vsq.qslmanager` |
| 图标源 | `assets/icon/qslmm_icon.png` |
| Android 图标 | `android/app/src/main/res/mipmap-*` + Adaptive Icon (`mipmap-anydpi-v26`) |

Flutter 内部页面标题不因应用显示名称变化而修改。
